2. Purpose and audience
Free, open-source utility for developers to view OpenAI Codex, Google Antigravity and Anthropic Claude Code quotas from their own desktop Companion: remaining quota, reset times and sample age in an iPhone dashboard/widgets. It is not a chatbot or content-generation service.

3. Setup and main features
No Statusline registration/login, user-generated content, paid content, ads, subscription or in-app purchase. No reviewer credentials or sample files are required.

Launch and tap View local demo / Ver demo local. This labelled fixed Codex example works offline in the app/widget; it is not live data or a notification simulation.

Optional live sync:
1. Install Companion from https://github.com/arvivares/statusline/releases/tag/v0.1.39 on macOS, Windows or Linux. Windows is an unsigned beta preview; macOS is signed/notarized.
2. Use your own compatible signed-in Codex, Antigravity or Claude Code installation. Companion discovers local services. Antigravity includes Google models only; Claude uses its documented local status line, not account credentials or API spending.
3. In Settings > Mobile sync, create a pairing and scan its private QR on iPhone or paste the private link. No Statusline login.
4. Select a service below the main quota. The small widget follows it; medium widgets show other available services. Absent services stay hidden; missing quota stays unknown. Claude defaults to five hours with a weekly fallback when reported.
5. Keep the computer awake, Companion running and devices connected. Open the app once after updating. WidgetKit controls refresh timing; snapshots are timestamped, not guaranteed real-time.

Notifications are optional and independently configured. Enable reset-credit and/or quota alerts and grant OS permission. Accepted choices persist if registration is delayed; a visible pending state retries while the app is active. After a real 0%, Companion can report confirmed short/weekly recovery. Unused-weekly alerts require at least 20% in the final hour. Timing/delivery is best effort. Disabling all removes push registration.

4. External services and data
- Local Codex, Antigravity and Claude Code report quota metadata. Credentials, prompts, code and conversations are not transmitted.
- Cloudflare Workers/D1 transports AES-256-GCM snapshots and credential hashes; decryption keys stay on paired devices. Push routing stores an encrypted Firebase Installation ID, language and category choices.
- Firebase Cloud Messaging/Apple APNs deliver opted-in alerts: service, event/window and expiration, not exact quota or account identity. This minimal push metadata is separate from end-to-end encrypted snapshots. No Firebase Analytics or advertising tracking.
- Camera scanning stays on-device without stored frames. WidgetKit/App Groups handle widgets/cache; Keychain stores pairing secrets.

5. Regions
China mainland remains excluded. Free pricing and features are consistent elsewhere, subject to third-party availability.

6. Regulated industry/material
No regulated-industry service or protected third-party content. Independent; not endorsed by OpenAI, Google or Anthropic. Names identify compatibility.
