## Descripción

Consulta tu uso semanal de Codex de un vistazo. Statusline convierte la cuota informada por tu instalación local en un panel para iPhone y un widget de pantalla de inicio.

DE UN VISTAZO

• Porcentaje restante del límite semanal
• Próxima fecha y hora de reinicio
• Última actualización correcta
• Widget Data Plane compacto
• Demo local sin cuenta, ordenador ni conexión

FUNCIONA DE FORMA INDEPENDIENTE

Puedes pegar manualmente la línea de cuota que devuelve /status, guardar la muestra en el iPhone y actualizar el widget sin instalar otra aplicación ni crear una cuenta.

SINCRONIZACIÓN PRIVADA OPCIONAL

Si quieres actualizaciones automáticas, instala Statusline Companion en Windows, Linux o macOS y empareja el teléfono mediante un QR de un solo uso o un enlace manual. Companion lee únicamente metadatos de cuota del Codex App Server local y cifra cada muestra antes de sincronizarla. El relay nunca recibe la clave de cifrado y no puede leer tu estado.

BAJO TU CONTROL

Statusline no solicita tus credenciales de Codex, claves de API, prompts, código fuente ni historial de conversaciones. No contiene anuncios, no exige una cuenta de Statusline y no tiene funciones de pago. El proyecto y el protocolo del relay son de código abierto.

Statusline es un proyecto independiente y no está afiliado, respaldado ni patrocinado por OpenAI. Codex es una marca de su respectivo titular.
