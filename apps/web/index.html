Help center
What exactly is Statusline?+

Statusline is an open source quota monitor for Codex, Antigravity's Gemini limits and Claude Code. The desktop companion shows the windows and reset times each source reports. Codex and Antigravity can sync encrypted readings to compatible phone apps and widgets; Claude Code is currently desktop-only.

Do I need an API key or a new account?+

No Statusline account or API key is required. Sign in through your provider's official local app or CLI. For Claude Code, explicitly enable the status-line connection and use a session that reports plan quota; API-key and cloud-provider sessions don't expose that quota. The offline demo needs no account.

Does the widget update in real time?+

No. Compatible widgets show the latest synced Codex or Antigravity sample from the local cache. Updates depend on the companion, your connection and iOS or Android restrictions. Check the sample timestamp. Claude Code is not available in mobile apps or widgets yet.

Which providers work today?+

The desktop companion supports Codex, Antigravity's Google Gemini quota and Claude Code. It does not show third-party model buckets from Antigravity. Claude Code reports only the windows available to its session, after you enable the bridge; live verification is on macOS, with Windows and Linux covered by automated tests pending native validation. Other integrations remain on the roadmap.

Is this an official provider product?+

No. Statusline is an independent project by Inmerzion. It is not affiliated with, sponsored or endorsed by OpenAI, Google or Anthropic. All product names and trademarks belong to their respective owners.
