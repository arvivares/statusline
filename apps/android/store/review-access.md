# Google Play review access

Statusline has no user account, subscription or paywall. The optional QR/manual pairing flow connects a phone to a desktop Companion, so Play Console records the app as having restricted functionality and supplies the reviewer path below.

## Access name

Review access (no account)

## Reviewer instructions

No username or password is required. On the main screen, tap **VIEW DEMO**. It creates a local 53% sample and updates the complete mobile UI and the Codex Data Plane widget without a network, account or desktop. QR pairing is an optional synchronization method, not an access gate. **PAIR DEVICE** opens the scanner and a manual-link fallback is available. The demo exposes all content needed for review; there is no paid or premium content.
