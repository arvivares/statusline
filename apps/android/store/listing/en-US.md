# Statusline

## App name

Statusline

## Short description

Track your weekly Codex limit and reset time in a private home-screen widget.

## Full description

See your weekly Codex usage at a glance. Statusline turns the quota reported by your local Codex installation into a focused mobile dashboard and home-screen widget.

AT A GLANCE

• Remaining weekly limit
• Next reset date and time
• Last successful update
• Compact 4 × 1 Data Plane widget
• Local demo that works without an account, desktop or network

PRIVATE SYNC

Install the open-source Statusline Companion on Windows, Linux or macOS, then pair your phone with a one-time QR code or manual link. The Companion reads only quota metadata from the local Codex App Server and encrypts each snapshot before synchronization. The relay never receives the encryption key and cannot read your usage snapshot.

BUILT FOR CONTROL

Statusline does not request your Codex credentials, API keys, prompts, source code or conversation history. It has no advertising SDK, no Statusline account and no paid tier. Pairing is optional: you can explore the complete interface and widget with the clearly labeled local demo.

Real synchronization requires Statusline Companion and access to a compatible public Statusline relay. The default community relay is provided for convenience, and the open-source project documents self-hosting.
