# Statusline

## App name

Statusline

## Short description

Codex, Antigravity and Claude Code quotas in a private home-screen widget.

## Full description

See your agent quotas at a glance. Statusline turns the metadata reported by your local Statusline Companion into a focused mobile dashboard and home-screen widget.

AT A GLANCE

• Remaining Codex weekly and short-window limits
• Antigravity's Google Gemini five-hour quota when enabled in Companion
• Claude Code five-hour and weekly limits when reported by your plan
• Focus on one service and keep the others visible in the app and taller widgets
• Next reset date and time
• Last successful update
• Compact 4 × 1 widget with the Still Signature segmented meter
• Local demo that works without an account, desktop or network

PRIVATE SYNC

Install the latest open-source Statusline Companion on Windows, Linux or macOS, then pair your phone with a one-time QR code or manual link. Companion discovers the local services you enable, reads only quota metadata from OpenAI Codex, Google Antigravity and Anthropic Claude Code, and encrypts each snapshot before synchronization. Only enabled services appear; missing limits stay unknown. Antigravity includes Google models only; Claude Code uses its documented local status line, not account credentials or API spending. The relay never receives the encryption key and cannot read your usage snapshot.

OPTIONAL NOTIFICATIONS

Opt in to alerts when an exhausted quota recovers or at least 20% of weekly quota remains during its final hour. A separate option sends a push when Companion detects new reset credits added by OpenAI for Codex. Permission is required and delivery is best effort. Firebase processes installation identifiers and minimal alert metadata, not your exact quota or account identity. Quota snapshots remain end-to-end encrypted.

BUILT FOR CONTROL

Statusline does not request your service credentials, API keys, prompts, source code or conversation history. It has no advertising SDK, no Statusline account and no paid tier. Pairing is optional: you can explore the interface and widget with the clearly labeled local Codex demo.

Real synchronization requires Statusline Companion and access to a compatible public Statusline relay. The default community relay is provided for convenience, and the open-source project documents self-hosting.
