# Statusline

## Nombre de la aplicación

Statusline

## Descripción breve

Consulta tu límite semanal de Codex y su reinicio desde un widget privado.

## Descripción completa

Consulta tu uso semanal de Codex de un vistazo. Statusline convierte la cuota informada por tu instalación local de Codex en un panel móvil y un widget para la pantalla de inicio.

DE UN VISTAZO

• Porcentaje restante del límite semanal
• Próxima fecha y hora de reinicio
• Última actualización correcta
• Widget Data Plane compacto de 4 × 1
• Demostración local sin cuenta, ordenador ni conexión

SINCRONIZACIÓN PRIVADA

Instala Statusline Companion, de código abierto, en Windows, Linux o macOS y empareja el teléfono con un código QR de un solo uso o un enlace manual. Companion solo lee metadatos de cuota del Codex App Server local y cifra cada estado antes de sincronizarlo. El relay nunca recibe la clave de cifrado y no puede leer tu estado de uso.

BAJO TU CONTROL

Statusline no solicita tus credenciales de Codex, claves de API, prompts, código fuente ni historial de conversaciones. No incluye publicidad, no exige una cuenta de Statusline y no tiene un plan de pago. El emparejamiento es opcional: puedes explorar toda la interfaz y el widget mediante la demostración local claramente identificada.

La sincronización real requiere Statusline Companion y acceso a un relay público compatible. El relay comunitario predeterminado se ofrece por comodidad y el proyecto de código abierto documenta cómo alojar uno propio.

Statusline es un proyecto independiente de código abierto y no está afiliado, respaldado ni patrocinado por OpenAI. Codex es una marca de su respectivo titular.
