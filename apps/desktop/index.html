How it works

Connecting adds a statusLine command to Claude Code's settings.json that runs Companion in bridge mode. Claude Code sends only its documented rate-limit windows; session, transcript and cost fields are discarded. An existing custom status line keeps running and is restored on disconnect.

Quota updates while a Claude Code session is open and after it receives a response. Pro and Max report five-hour and weekly windows; Enterprise seats may report only the five-hour window; API-key sessions report none.
