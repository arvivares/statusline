# Archivo de diseño

Este directorio conserva exploraciones visuales históricas que condujeron a Data Plane. Sirven como registro de decisiones, no como documentación vigente del producto ni como fuente de configuración.

Algunas capturas muestran flujos descartados, como CloudKit o emparejamiento por correo. La implementación y el contrato actuales están documentados en el [README principal](../../README.md) y en [Statusline Relay Protocol v1](../../protocol/statusline-relay-v1.md).
