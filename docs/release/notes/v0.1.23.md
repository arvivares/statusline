# Statusline 0.1.23 Beta

Release candidate: automatic Antigravity discovery and the approved Still
Signature focus + watchlist layout. Preparing this source is not evidence that
installers have been built, signed or published. Store submissions are separate.

## What's changed

- Companion discovers supported Antigravity Desktop and AGY CLI installations
  automatically. No manual Add service or executable path is required. Only
  installed services appear; Claude is not offered and AGY's non-Google quotas
  are discarded.
- First discovery prefers Desktop, then CLI, and remembers that source before
  reading its session. Existing manual choices and disabled services survive
  the upgrade. A failed read or a later Desktop installation never silently
  switches a user's account. Settings retains manual choices and Scan again.
- Restore Still Signature's main quota focus and open **Other limits** rows,
  replacing provider tabs. Select a row to bring that provider into focus;
  switch between weekly and short windows without changing mobile sync.
- Keep the compact 340 × 500 window, rounded surface, restrained typography,
  spaced percentage and segmented meter with a fully white terminal stripe.
  EN/ES, keyboard focus and explicit unavailable/stale readings are preserved.
- Automatic lookup uses conventional OS/current-user installation locations,
  not arbitrary inherited project PATH entries. Advanced custom paths remain
  explicit. The native five-minute scheduler remains independent of Codex.

## Compatibility and upgrade

Antigravity remains **Companion-only**. Android/iPhone apps and widgets continue
to show Codex. The relay v1 schema, encrypted Codex payload, AAD, endpoint, secure
credentials and pairing QR are unchanged. No relay migration, deployment or
re-pairing is required. Changing local display focus does not publish AGY data
or increase relay traffic.

The release inventory includes macOS universal DMG/PKG, Windows NSIS/MSI, Linux
AppImage/DEB/RPM and signed Android APK/AAB. Android is aligned to `0.1.23`
(`versionCode 19`), with generated shared strings but no new mobile provider UI.
iOS is not rebuilt by this workflow; no Google Play, TestFlight or App Review
submission is included.

Windows remains an **unsigned preview**. Updater signatures authenticate payload
integrity, not an Authenticode publisher. SmartScreen or organizational policy
may warn or block installation. Do not disable security protections.

## Known beta limitations

- Local frontend/release checks passed: 251 tests passed, one intentionally
  skipped; TypeScript, production build, EN/ES catalog and documentation checks.
- Shared production runtime tests passed on macOS: 98 passed, one ignored.
  Coverage includes source precedence, preference migration, opt-out, source
  pinning across restart and the unchanged relay encryption fixture.
- A real macOS automatic-discovery probe found Desktop and returned Google-only
  quota using a private temporary Companion configuration. It did not modify
  saved preferences, accounts or pairing. This is not an installed-upgrade test.
- Browser previews covered EN/ES/fallback, one/two-service and unavailable
  states, window switching, keyboard/settings focus and the compact layout.
  A synthetic third row tested layout capacity only; it is not a new provider.
- Native CI on Windows/Linux/macOS and signed packaging must pass before
  publication. Real signed-in Windows/Linux AGY sessions, installed updates,
  pairing preservation and hidden-window timing still need physical-device QA.
- Desktop uses an internal vendor API, not an officially supported public
  quota endpoint. Future changes fail unavailable. Windows/Linux publisher
  trust is not independently verified by the adapter; use official installs.
  Live macOS samples had full quota; non-full/reset behavior is fixture-tested
  but still needs live consumption verification.
