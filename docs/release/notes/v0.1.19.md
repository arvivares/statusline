# Statusline 0.1.19 Beta

A smaller Still Signature companion, automatic update notices when you open it,
and a fix for macOS update installation.

## What's new

- The companion is now 340 × 500 logical pixels instead of 400 × 600. Quota
  digits shrink from 120 to 88 px, with smaller headings and tighter spacing.
  The gold segmented meter, white final active stripe and separated percent
  symbol remain. Native mobile apps and widgets are not shrunk by this change.
- Opening the companion checks for updates automatically when that preference
  is enabled. A discovered version opens the update popup without clicking
  Updates. Recent checks are reused for 15 minutes; background checks remain
  every six hours, with a two-second hidden-startup fallback.
- **Later** now snoozes the notice for that opening. Reopening reminds you again;
  ordinary focus changes do not spam popups or interrupt other applications.
  Disabling automatic checks remains supported. Installation still requires
  an explicit **Download & install** confirmation.
- macOS correctly passes an inline Apple signing requirement to `codesign`.
  The older invocation treated that requirement as a missing file and stopped
  installation. Signature, signing-team, version and rollback checks stay enabled.

## macOS: one manual upgrade is required

The broken updater is inside the already-installed `0.1.17`/`0.1.18` app. Those
versions cannot apply this fix themselves: **install the corrected DMG or PKG
manually once** after publication. Subsequent versions use the fixed updater.
Read-only or system-managed application locations still require manual installation.

Windows keeps its existing MSI/NSIS automatic-installation path. Linux AppImage
keeps its updater; DEB/RPM use the official release page and package manager.

## Downloads

- macOS: signed/notarized universal DMG and PKG for Apple Silicon and Intel.
- Windows x64: **unsigned preview** NSIS `.unsigned.exe` and `.unsigned.msi`.
  Updater signatures do not provide Authenticode publisher trust. SmartScreen or
  organization policy may still warn or block installation; never disable security
  protections.
- Linux x64: AppImage, DEB and RPM with detached OpenPGP signatures.
- Android: signed APK/AAB, `0.1.19` (`versionCode 15`), with unchanged mobile layout.
  Update through your original distribution channel.

GitHub publication does not submit an app to Google Play or App Review. iOS
continues through its separate manual build and TestFlight/App Store workflow.

## Known beta limitations

The macOS fix passed real Apple-signature parsing tests and a rehearsal replacing
only temporary copies with an independently signature-verified published payload.
This does not prove a live `0.1.19 → later version` restart or pairing preservation;
those remain physical-device QA checks. The maintainer reports Windows updated
successfully to `0.1.18`, without yet confirming both MSI and NSIS separately.

Check the smaller window, update popup, settings, EN/ES, 100% quota and error
states on native Windows/macOS displays and Linux/XWayland. Browser previews
do not prove native compositor behavior. Sleep, connectivity and GitHub rate
limits can delay update discovery. Read [companion updates](../../architecture/companion-updates.md)
for the installation and privacy constraints.

## Verify before installing

These are candidate notes, not proof of publication. Only the reviewed, signed-tag
release pipeline may publish the installers after signature, inventory, checksum
and provenance verification. Check the files against `SHA256SUMS.txt` and its
detached signature; see the [release runbook](../release-runbook.md#independent-verification).
