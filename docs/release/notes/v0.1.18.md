# Statusline 0.1.18 Beta

Still Signature brings a calmer, more focused quota view to Statusline Companion
and Android: one warm dark surface, larger readings and the segmented meter from
the Statusline logo. Codex sync, encrypted pairing and update controls remain
available.

## What's new

- A rounded companion window with simpler hierarchy, without background grids
  or nested dashboard cards.
- A gold segmented quota meter with a fully white final active stripe, including
  at 100%. Empty or zero readings do not display a white marker.
- More breathing room between the quota number and its percent symbol.
- Matching Android app and widget styling. The widget keeps its 4 × 1 default
  size and reports the sample's age rather than claiming cached data is live.
- English and Spanish follow the system language; other languages use English.

This is a visual update. Codex remains the only quota provider; Antigravity and a
multi-provider view are not included. Existing refresh, pairing, focus-loss/tray
behavior and the companion updater are preserved.

## First installation and downloads

- macOS Apple Silicon and Intel: universal DMG and PKG, signed and notarized.
- Windows x64: **unsigned preview** NSIS `.unsigned.exe` and `.unsigned.msi`.
  Updater signatures are separate from Authenticode: SmartScreen or organization
  policy can still warn or block installation. Never disable security protections.
- Linux x64: DEB, RPM and AppImage, with detached OpenPGP signatures.
- Android: signed APK and AAB, `0.1.18` (`versionCode 14`). Update through the same
  channel you used to install; Google Play submission remains a separate action.

Companion `0.1.17` users can check **Updates** for this newer release. Downloading
and installing requires confirmation. macOS, Windows MSI/NSIS and Linux AppImage
use their corresponding updater payload; DEB/RPM use the official release page
for package-manager installation. Earlier companion versions require a manual
download. See [companion updates](../../architecture/companion-updates.md).

The iPhone design is present in source but is **not distributed by this release**.
GitHub Actions does not build/upload iOS, submit to Google Play or change App
Review. Existing store versions and screenshots are not updated by these assets.

## Known beta limitations

Native corner clipping depends on the compositor. Linux retains its existing
X11/XWayland requirements. The macOS companion uses Tauri's transparent-window
support for direct DMG/PKG distribution, not a Mac App Store build.

Before broad rollout, complete physical-device checks for native corners,
Windows first launch, Linux/XWayland rendering, tray/focus/picker interactions,
and Android widgets at minimum size and larger text in EN/ES, including empty and
100% readings. CI and browser previews do not replace native visual QA.
See [Still Signature](../../architecture/still-signature.md).

A real **0.1.17 → 0.1.18** upgrade still needs validation on macOS, Windows MSI,
Windows NSIS and Linux AppImage, including restart and pairing preservation.
Only a running companion checks for updates; sleep, connectivity and GitHub API
limits can delay discovery. No Codex credentials, quota snapshots or pairing
secrets are sent in update requests; GitHub receives normal request metadata.
See the [privacy policy](../../../PRIVACY.md).

## Verify before installing

The pipeline publishes only after all required installers, updater signatures,
checksums and provenance pass validation. Verify the downloaded files against
`SHA256SUMS.txt` and its detached signature using the release's public signing key.
Preparing these notes is not proof that the release pipeline has completed.
See the [release runbook](../release-runbook.md#independent-verification).
