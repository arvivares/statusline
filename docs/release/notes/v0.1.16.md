# Statusline 0.1.16 Beta

The companion now hides when you click outside its window or switch to another
application, while quota synchronization continues in the background. The Data
Plane interface and existing encrypted pairings are unchanged.

## What's changed

- Use the same focus-loss dismissal policy on macOS, Windows and Linux. A short
  deferred focus check avoids dismissing a window that has already regained focus.
- Preserve the tray/menu-bar toggle and protect it from the hide-and-reopen race
  during icon clicks. Close hides the window; only Quit stops the companion.
- Keep the companion visible while its native Codex file picker is open, restore
  dismissal after selection or cancellation, and prevent duplicate dialogs.
- Detect compatible Codex runtimes embedded in Windows desktop applications via
  read-only, current-user MSIX metadata and conventional install locations. Paths
  are not tied to a username, drive letter or package version. Saved paths and
  CLI fallback remain available; no credentials or PATH settings are changed.
- Add regression coverage for window interactions, desktop discovery and the
  separate iOS widget relay configuration. The production runtime tests pass on
  Windows, Linux and macOS; the PowerShell fixture also passes on Windows 5.1.
- Keep shared English/Spanish help text consistent across the app sources.

## Downloads

- macOS Apple Silicon and Intel: universal DMG and PKG, signed and notarized.
- Windows x64: **unsigned preview** NSIS `.unsigned.exe` and `.unsigned.msi`.
  These do not have Authenticode publisher trust. SmartScreen or organization
  policy may warn or block them; never disable security protections.
- Linux x64: DEB, RPM and AppImage, each with a detached OpenPGP signature.
- Android: signed APK and AAB, `0.1.16` (`versionCode 12`). The mobile widget's
  refresh policy is unchanged. Google Play submission is separate; use the same
  installation channel when updating because direct APK and Play signing differ.

iOS remains `1.0.1 (6)`, uploaded separately for TestFlight processing. This source
fixes the empty widget relay setting found in build 5 and validates both packaged
endpoints during every app build. GitHub Actions does not compile or upload iOS,
replace its App Review submission or change the published `1.0 (4)` release.
Build-6 TestFlight availability and the distribution-signed upgrade still need
verification; build 5 must not be publicly released.

## Known beta limitations

Focus dismissal requires focus-loss events from the operating system. Linux tray
mouse events vary by desktop; use the existing Show menu to reopen the window.
Native focus, tray and file-picker interactions still need clean-machine manual
QA on each platform. See the [window checklist](../../architecture/companion-window.md).

Windows desktop-only detection still needs validation on the affected physical
device. An installed ChatGPT/Codex desktop app must include a compatible Codex
runtime; a graphical app alone does not guarantee it or a reusable signed-in
session. The App Server protocol remains experimental.

The five-minute desktop refresh is a scheduler target while the computer is awake,
not a guarantee of a successful quota read. Sleep, network and authentication can
delay updates. WidgetKit controls actual iPhone reload times; Android scheduling
is unchanged. AppImage still uses X11/XWayland and host graphics libraries.

## Verify before installing

The pipeline publishes this prerelease only after all required installers,
signatures, checksums and provenance pass validation. Follow the
[release runbook](../release-runbook.md) to verify downloads. Signed checksums
authenticate integrity but do not provide Windows Authenticode publisher trust.
Preparing these notes is not proof of completed builds or store approval.
