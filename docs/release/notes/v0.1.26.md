# Statusline 0.1.26 Beta

Candidate: Claude discovery foundation and visible GitHub releases. Preparing
this file does not publish the tag or installers.

## What's new

- Companion passively detects Claude in conventional CLI/Desktop locations on
  macOS, Windows and Linux. Only a detected installation creates a Claude row in
  the existing Still Signature focus/watchlist; absent services stay hidden.
- Claude's row clearly reports that automatic quota reading is not available yet.
  Installation detection does not imply login or a usable quota source. No Claude
  credentials, conversations, settings or agent processes are accessed.
- The documented Claude statusline quota format has a tested normalization
  adapter, ready for a future supported transport. This release does **not**
  read or display live Claude quota.
- `services-v1`, Codex's legacy projection and existing pairings remain compatible.
  Current mobile clients continue showing Codex/Gemini and ignore the experimental
  Claude presence entry. No relay migration or new pairing is required.
- From this version, the verified GitHub release is published without the
  Pre-release flag and marked Latest, making downloads visible in the repository
  sidebar. Product maturity remains beta; this is not a signing certification.
  Earlier releases, including v0.1.25, are unchanged.
- Every GitHub asset receives a platform-oriented display label before publication,
  so Windows, macOS, Linux and Android downloads are easy to distinguish. Labels
  do not rename files or alter updater URLs, signatures, checksums or payloads.
  The Android AAB is explicitly identified as a Google Play artifact that is not
  directly installable; end users should choose the APK.

## Known beta limitations

- Claude live quota, account/source validation, custom installation layouts and
  Windows Store/MSIX discovery need further work. Windows/Linux discovery tests
  use fixtures; they are not proof of real-session compatibility. Details are in
  the [Claude source assessment](https://github.com/arvivares/statusline/blob/v0.1.26/docs/architecture/claude-sources.md).
- Windows installers remain **unsigned previews without Authenticode**. Their
  filenames contain `.unsigned`; SmartScreen or organizational policies may warn
  or block installation. Do not disable security protections. Signed checksums,
  provenance and Tauri updater signatures verify integrity, not Windows publisher
  identity. SignPath approval is not required for this explicit beta policy.
- Linux signatures, macOS Developer ID/notarization and Android release signing
  remain required before publication.
- iOS remains a separate manual App Store delivery. This pipeline does not build
  or replace the approved iOS app. Android APK/AAB artifacts are built together
  with desktop installers; Google Play submission is separate.
