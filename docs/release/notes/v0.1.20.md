# Statusline 0.1.20 Beta

Still Signature now extends to companion settings, with new English and Spanish
product screenshots in the README.

## What's new

- Settings shares the companion's compact 340 × 500 surface: simple Codex and
  Mobile sync tabs, aligned information rows and rounded actions, without the
  old telemetry grid or nested panels.
- Clear sentence-case labels in English and Spanish replace legacy technical
  headings. Long executable paths and error messages wrap and scroll.
- Setup help is expandable, opens when Codex is missing or invalid, and stays
  out of the way when the runtime is verified.
- Pairing gives the QR more room and places it before server metadata. The
  private link remains available in a keyboard-operable disclosure.
- Keyboard navigation includes the disclosures; Tab stays inside Settings,
  arrow keys switch tabs and Escape restores focus to the previous control.
  The underlying quota view is inert while Settings is open.
- Both READMEs include eight language-matched captures of the actual frontend
  and native iPhone app using isolated demo data. The desktop preview reads its
  version from the project, so future captures do not retain an old hard-coded
  version label. The iPhone images show current source, not App Store rollout.

## Downloads and upgrade notes

- macOS: signed/notarized universal DMG and PKG for Apple Silicon and Intel.
  **Users still on 0.1.17/0.1.18 must install a DMG or PKG manually once** to
  receive the updater fix introduced in 0.1.19. The fixed updater is retained;
  a live 0.1.19-to-0.1.20 upgrade and pairing preservation still need device QA.
- Windows x64: **unsigned preview** NSIS `.unsigned.exe` and `.unsigned.msi`.
  Updater signatures verify downloads but do not provide Authenticode publisher
  trust. SmartScreen or organization policy can warn or block installation;
  never disable security protections.
- Linux x64: AppImage, DEB and RPM with detached OpenPGP signatures. AppImage
  retains its updater; DEB/RPM updates use the release page and package manager.
- Android: signed APK/AAB, `0.1.20` (`versionCode 16`), with unchanged mobile
  layout in this patch. Update through your original distribution channel.

GitHub publication does not submit builds to Google Play, TestFlight or App
Review. iOS remains a separate manual delivery. Core quota, encryption, relay,
native window behavior and update-installation logic are unchanged in this patch.

## Known beta limitations

The settings passed browser checks at 320 × 480 and 340 × 500 in both languages,
including long paths, expanded help, QR layout and keyboard navigation. Frontend
tests, shared localization and Markdown links passed locally. Native iPhone
captures passed two UI tests on an isolated, locally signed simulator.

These checks do not replace native Windows/macOS/Linux compositor, file-picker,
QR-camera or live-upgrade QA.
