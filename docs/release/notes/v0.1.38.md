# Statusline 0.1.38 Beta

A compatible dependency-maintenance release. It preserves the existing
Companion design, automatic service discovery, encrypted synchronization,
pairings and notification preferences, including the macOS ChatGPT discovery
fix shipped in 0.1.37.

## What's changed

- Update native and JavaScript Tauri to 2.12.2, updater tooling to 2.13.2,
  rustls to 0.23.45 and compatible runtime libraries.
- Update Vite to 8.3.4 and source-map-js to 1.2.2 for desktop and website.
- Update Android build tooling to Gradle 9.8.1 and Kotlin Compose 2.4.21.
  Android 6/API 23 support is retained; WorkManager 2.11.2 and Firebase BoM
  34.19.0 remain selected instead of the API-24-only updates.
- Update SHA-pinned build actions and relay development tooling. Wrangler
  4.149.0 uses Sharp 0.35.5 without the obsolete override. No production relay
  deployment or database migration is included.

## Distribution

Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG and Android
**0.1.38 (35)** APK/AAB are built from the same signed tag. GitHub publication
is configured as **Latest**; the product remains beta. Updater keys, asset
filenames and signing/inventory/provenance requirements are unchanged.

Windows installers remain **unsigned previews without Authenticode**.
SmartScreen or organizational policy may warn or block them; do not disable
security protections. Linux signatures, macOS Developer ID signing and
notarization, Android signing and updater signatures remain mandatory.

The separately requested Google Play beta update uses the same Android AAB
and preserves the existing tester lists. iOS remains **1.1.3 (12)** and its
existing TestFlight-tested build is the separate App Store candidate; this
GitHub pipeline does not compile or submit iOS. Store review, propagation and
public availability are tracked separately and are not implied by this tag.

## Validation

- The individual dependency PRs passed scoped local checks and fresh CI on
  macOS, Windows and Linux, plus Android and website checks where applicable.
  This release must also pass its own PR, preflight and packaging gates.
- Installer smoke tests, final signatures, full inventory, checksums and
  updater metadata must succeed before publication. They do not replace every
  clean-machine or physical-device test.

## Known beta limitations

- The account holder confirms iOS TestFlight validation and requests production
  delivery without another direct device installation. No new physical-device
  test is claimed by this release preparation.
- Existing five-minute Companion collection and best-effort mobile, widget and
  push scheduling are unchanged. Android Doze and iOS scheduling can delay work.

## Verify before installing

Follow the [release verification guide](../release-runbook.md#independent-verification)
before installing. Never share pairing codes, credentials or unreviewed logs.
