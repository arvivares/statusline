# Statusline 0.1.40 Beta

This coordinated release prepares iOS **1.1.5 (14)** with a quieter quota screen
and responsive notification controls. Existing agent discovery, encrypted sync,
pairings and widget data remain compatible.

## What's changed

- Refresh and Settings are icon buttons in the upper-right corner of the iOS
  overview, with localized accessibility labels and 44-point touch targets.
- Settings groups notification preferences, private pairing/sync, and Privacy /
  Support. The overview retains the approved Still Signature quota presentation;
  no nested settings cards or manual quota input are introduced.
- Notification switches stay usable while registration is pending. The latest
  choice wins, including rapid ON → OFF → ON changes. Removing all alerts
  immediately withdraws local consent and cancels SDK waits.
- Issued relay writes are drained before unregistering. Late callbacks cannot
  restore a withdrawn preference, and a failed unregistration remains pending
  for retry. Diagnostic logs contain only named stages, outcomes and error codes,
  never installation IDs, tokens, pairing links or quota readings.
- An APNs token can be reused only after a real callback in the current process
  while the operating system still reports registration. Permission and delivery
  readiness remain separate; temporary failures are never presented as success.
- Disable Firebase delegate proxying for SwiftUI, retaining the existing explicit
  APNs mapping and consent-controlled initialization.

## Distribution

Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG and Android
**0.1.40 (38)** APK/AAB are built from this signed tag. Desktop collectors and
Android behavior are unchanged except for coordinated versioning and shared
translations. This is not an Android redesign.

Windows remains an **unsigned preview without Authenticode**. SmartScreen and
organizational policies may warn or block installation; do not disable security
protections. Linux signatures, macOS signing/notarization, Android signing,
updater signatures, checksums and complete-inventory gates remain mandatory.

iOS is uploaded manually to App Store Connect, not distributed as a GitHub IPA.
GitHub publication does not establish Apple approval or Google Play availability.
No relay deployment, migration, credential access or re-pairing is required.

## Validation

Regression tests cover delayed registration, independent choices, interrupted
APNs waits, late PUT/DELETE ordering, rapid toggles and durable failed cleanup.
Native UI tests cover the localized settings route and preserve service focus.
See the [iOS delivery record](../../../apps/apple/store/validation-1.1.5.md) for
actual build, device and submission evidence; preparation is not certification.

## Known beta limitations

Push delivery and widget refresh remain best effort and subject to OS scheduling.
Local development delivery does not establish App Store APNs delivery on every
supported device or OS version.
