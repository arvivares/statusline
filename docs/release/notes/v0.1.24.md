# Statusline 0.1.24 Beta

Candidate: Antigravity sync for iPhone and widgets. Installers are not considered
published until the release pipeline and independent asset verification pass.
iOS 1.1.0 (9) is a separate manual TestFlight delivery, not an App Store release.

## What's new

- Companion publishes only the services present on that user's computer: Codex
  and/or Antigravity's Google Gemini quotas. No Claude/GPT quotas from AGY, API
  keys, account emails or local paths are sent to mobile.
- iOS adopts Still Signature focus + watchlist. Select Codex or Gemini, inspect
  weekly/five-hour quota without mixing their meaning, and keep the segmented
  meter's fully white terminal stripe and spaced percentage.
- The existing small widget follows the app's selected service; the medium
  widget shows the main reading and its other service. There are no empty AGY
  slots for Codex-only users. Widget network reads remain independent of opening
  the app; operating-system refresh scheduling is still opportunistic.
- Offline snapshots remain visible with their age. Explicit removal, unavailable
  data, late responses and account changes cannot silently restore another
  service or pairing's cached quota. EN/ES and English fallback are preserved.

## Compatible relay upgrade

Self-hosters: apply migration 0003 before updating the Worker. See the normative
[services-v1 extension](../../../protocol/statusline-services-v1.md). It adds
nullable storage without rotating credentials, replacing the Codex projection
or requiring a new QR. New clients negotiate with one snapshot request; old
Android/iOS clients continue receiving Codex. Old relays still accept Codex from
the new Companion but cannot provide Gemini to mobile.

Nearby native collector results are coalesced before publishing. A slower
collector can cause a second publication; no per-provider mobile polling is
added. The native five-minute collection cadence remains unchanged.

## Known beta limitations

- macOS universal DMG/PKG, Windows NSIS/MSI, Linux AppImage/DEB/RPM and Android
  APK/AAB are generated by the release workflow. Android 0.1.24 (20) aligns the
  release/shared catalogs but remains Codex-only; no Play Console upload is
  implied. iOS is never built by GitHub Actions.
- Windows installers remain unsigned previews. Updater signatures protect
  payload integrity, not an Authenticode publisher. SmartScreen or organizational
  policies may block installation; do not disable security protections.
- Actual signed-in Windows/Linux Antigravity sessions, upgraded desktop/mobile
  pairs and delayed WidgetKit refresh still require real-device beta testing.
- The latest Apple production build remains separate from this TestFlight
  candidate. No App Review replacement or public iOS rollout is included.

## Verify before installing

Use the [release verification guide](../release-runbook.md#independent-verification)
before installing. Never share private QR links or vendor credentials.
