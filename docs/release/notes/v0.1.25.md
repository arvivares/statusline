# Statusline 0.1.25 Beta

Candidate: service-aware synchronization for Android. Companion publishes the
services enabled on each user's computer, and Android now presents the same
Still Signature focus + watchlist model already available on iOS. Existing
pairings and Codex-only clients remain compatible.

## What's new

- Android receives the negotiated `services-v1` snapshot from Companion through
  the existing relay and pairing. The relay still cannot read the encrypted
  quota payload.
- Android shows only the services present in that Companion: Codex and/or
  Antigravity's Google Gemini quota. Claude and GPT limits are not included.
- The main view supports Codex's weekly/short windows and Gemini's five-hour
  window without relabeling one as the other. The selected service is persisted
  locally and the medium widget adds the other available service as a watchlist.
- The compact 4 × 1 widget follows the focused service, keeps the segmented
  meter's white terminal stripe and remains cache-only. An explicit empty
  inventory never creates a fake Codex or Gemini slot.
- Upgrading from an older Android build migrates its last Codex reading without
  requiring a new QR. Legacy relay responses continue to work.

## Compatible relay upgrade

No new relay deployment is required for this client when the existing
`services-v1` extension is already active. Self-hosters should keep migration
0003 applied before the compatible Worker and can roll back without rotating
tokens, channel IDs or pairing keys. See the normative
[services-v1 specification](../../../protocol/statusline-services-v1.md).

## Known beta limitations

- Android physical-device QA still needs to be completed on the Alpha track,
  including a Codex-only Companion, a Gemini-only Companion and a two-service
  Companion, both widget sizes, offline cache and upgrade without re-pairing.
- Windows installers remain unsigned previews. Authenticode publisher trust is
  not present and SmartScreen or organizational policies may block installation;
  do not disable security protections. Tauri updater signatures protect payload
  integrity, not Windows publisher identity.
- iOS remains a separate manually delivered App Store build. This release does
  not compile or replace the approved iOS binary.
