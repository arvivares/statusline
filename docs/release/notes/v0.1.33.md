# Statusline 0.1.33 Beta

Optional quota alerts for Codex, Google Antigravity and Claude Code, using the
services already detected in your Companion. Existing Codex reset-credit alerts
remain independent, and existing pairings are preserved.

## What's new

- **Quota recovered:** notify when a fresh reading confirms that an exhausted
  5h or weekly allowance has reset. A real 0% reading must have been observed;
  merely reaching the expected reset time does not trigger an alert.
- **Weekly reminder:** notify once in the last hour before reset when at least
  20% remains. The usual five-minute collection cadence makes this approximately
  55–60 minutes before reset, not an exact scheduled alarm.
- **Independent preferences:** enable Quota notifications separately from Codex
  reset-credit notifications. Existing credit subscriptions do not automatically
  subscribe to the new category. Turning off one category preserves the other.
- **Safe retries:** opaque pending event IDs and cycle deduplication survive
  Companion restarts. Missing, stale or invalid readings do not claim recovery.
- **Privacy and compatibility:** pairing and encrypted snapshot formats remain
  unchanged. Alerts disclose service, event/window kind and delivery expiry to
  the relay and FCM/APNs, but no exact quota, account ID or vendor credentials.
  A weekly reminder necessarily reveals that its threshold condition was met.
- **Relay tooling:** upgrade Wrangler to 4.147.0, resolving the known transitive
  Undici advisories covered by the current npm audit.

## Distribution and rollout

Includes Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG and
Android `0.1.33 (29)` APK/AAB, plus verified Companion updater payloads.
Asset filenames and the embedded updater key are unchanged.

Windows installers remain **unsigned previews without Authenticode**.
SmartScreen or organizational policy may warn or block them; do not disable
security protections. Linux signatures, macOS Developer ID signing/notarization,
Android signing and final-payload updater signatures remain mandatory.

Deploy additive D1 migration 0005 before the compatible relay Worker. Preserve
existing channels, credentials and the push encryption key. Older mobiles remain
Codex-credit-only; older relays are detected without sending new event requests.
The operator authorized this compatible production relay rollout.

iOS source includes the new control, but its recorded store build remains
`1.1.2 (11)`. A new signed build and separate TestFlight/App Store submission are
required before iPhone users can opt into this category. This GitHub release
does not upload to either mobile store or change device pairings.

## Validation

- Rust production-module tests cover all three providers, both windows, exact
  thresholds, timestamps, once-per-cycle behavior, persistence and retry.
- Relay tests cover publisher/reader separation, opt-ins, malformed input,
  budgets, deduplication, retry, FCM/APNs expiration and a real SQLite upgrade
  preserving old subscriptions and encrypted snapshots.
- iOS unit tests and app/widget compilation passed in the simulator. Android
  unit tests, lint and debug compilation passed, including concurrent Firebase
  renewal and opt-out protections. These are not physical push delivery tests.
- Frontend, localization, public privacy pages and release-policy checks passed.
- Native cross-platform checks, installer smoke tests, signature and complete
  inventory/provenance gates must pass before automatic publication.

## Known beta limitations

- Companion must be running, awake and connected, with fresh provider quota
  metadata. Sleeping computers or unavailable vendor caches can miss an alert.
- Push delivery is best-effort. Synthetic test fixtures do not prove real quota
  rollover or physical delivery of the new message category; these remain device QA.
- One source/account per provider is supported. Vendor account switches that
  expose no identity cannot be distinguished reliably from quota changes.
- Update store privacy declarations before distributing the new mobile build
  through Play Console or App Store Connect.
- Windows remains unsigned for Authenticode; Linux DEB/RPM updates still use
  package-manager downloads. Strict Clippy flags pre-existing style warnings;
  no new warning was introduced by the quota detector.
