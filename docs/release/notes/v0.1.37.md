# Statusline 0.1.37 Beta

Restores automatic Codex quota discovery after the macOS ChatGPT app changed
its bundled runtime layout. Existing services, pairings, encrypted mobile sync
and notification preferences are preserved.

## What's changed

- Detect the current `Contents/Resources/codex-cli/bin/codex` launcher and
  nested `CodexCLI.app/Contents/MacOS/codex` runtime inside ChatGPT.app and
  Codex.app. Retain the legacy `Contents/Resources/codex` layout.
- Keep discovery bounded to system and per-user Applications, with no
  version-directory pin, recursive scan or graphical-app launch.
- Verify each supported launcher. A missing or broken old launcher or current
  shim no longer hides a working bundled runtime.
- Preserve explicitly saved .app packages across layout changes. Diagnostics
  and real quota reads use the same verified selection; CLI fallback and source
  precedence are unchanged.

No separate Codex CLI is required when the supported bundled runtime can use
the local session. Statusline does not copy account files, extract credentials
or initiate login automatically. See [Codex runtime sources](../../architecture/codex-sources.md).

## Distribution

Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG and Android
**0.1.37 (34)** APK/AAB are built from the same signed tag. Android changes are
release metadata only. GitHub publication is configured as **Latest**; the
product remains beta. Asset names and updater signing keys are unchanged.

Windows installers remain **unsigned previews without Authenticode**.
SmartScreen or organizational policy may warn or block them; do not disable
security protections. Linux signing, macOS Developer ID signing/notarization,
Android signing and updater signatures remain mandatory.

iOS stays recorded at **1.1.3 (12)**. This release does not upload to App Store
Connect or Play Console, deploy the relay, migrate D1 or change live pairings.

## Validation

- All 20 local discovery tests passed, including both app names, system/per-user
  roots, spaces, stale saved paths, broken launchers, nested fallback and saved
  packages that change layout. The fixtures use no real accounts or relay.
- The maintainer confirmed a ready live quota through the production helper,
  using ChatGPT **26.1002.52244** and its bundled **codex-cli 0.162.0-alpha.2**
  on macOS, with no saved path or environment override. No standalone CLI
  runtime was used.
- The broader local runtime suite passed 165 tests with one ignored. Its one
  codesign trust failure was reproduced on unchanged main in the restricted
  automation environment; signature checks were not bypassed.
- Native macOS/Windows/Linux CI and release packaging gates must pass before
  publication, including signing, installer smoke tests, inventory, checksums,
  updater metadata and build provenance.

## Known beta limitations

- Observed ChatGPT layouts are not a stable vendor packaging contract.
  Authentication compatibility still depends on OpenAI's local session mode.
- A live read on this Mac is not proof of a never-used CLI profile or a final
  installed Companion upgrade. Windows/Linux real-account QA remains separate.
- Existing five-minute collection and best-effort mobile/push scheduling are
  unchanged. Pre-existing strict-Clippy warnings are not resolved by this fix.

## Verify before installing

Follow the [release verification guide](../release-runbook.md#independent-verification)
for checksums, Linux signatures and build provenance. Never share pairing codes,
credentials or unreviewed diagnostic logs.
