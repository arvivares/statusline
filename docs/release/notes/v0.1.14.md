# Statusline 0.1.14 Beta

This beta lets the macOS companion use Codex embedded in ChatGPT/Codex.app without
installing a separate Codex CLI. The Data Plane interface, existing pairing and
encrypted relay protocol are preserved.

## What's changed

- Detect the bundled runtime in system/user Applications directories. A manually
  selected `.app` package is supported for renamed or nonstandard installations.
- Show `DESKTOP APP` / `APP DE ESCRITORIO` as the source and update English/Spanish
  guidance so installing a standalone CLI is no longer the only suggested flow.
- Use the same verified candidate selection for diagnostics and usage reads;
  invalid/missing executables fall back to the next source. Explicit paths retain
  priority over automatic discovery.
- Report an absent local account as a sign-in state without issuing a quota request
  that would fail. No automatic sign-in, token extraction or account migration.
- Test the production runtime modules independently of Tauri/WebView on macOS,
  Windows and Linux; retain the previous Linux packaging/rendering fixes.

## Downloads

- macOS Apple Silicon and Intel: universal DMG and PKG, signed and notarized.
- Windows x64: **unsigned preview** NSIS `.unsigned.exe` and `.unsigned.msi`.
  SignPath onboarding is pending. These files have no Authenticode signature;
  SmartScreen may warn or block them. Never disable security protections.
- Linux x64: DEB, RPM and AppImage with detached OpenPGP signatures.
- Android: signed APK and AAB, version `0.1.14` (`versionCode 10`). No new Android
  behavior; Google Play distribution still requires a separate upload.

Use the same installation channel when updating. The direct APK and Google Play
use different signing keys. iPhone stays at `1.0 (4)`; this release does not build
iOS, submit to TestFlight or change the public App Store version.

## Known beta limitations

Only macOS desktop-app bundle discovery is newly supported. Windows/Linux retain
their CLI lookup. Older ChatGPT apps without a bundled Codex runtime are unsupported.
Desktop authentication may be ephemeral or externally managed, so automatic reuse
of an app session is not guaranteed; the runtime may require its own explicit login.
See [Codex sources and the clean-Mac checklist](../../architecture/codex-sources.md).
Physical validation on a Mac with no CLI history remains pending at preparation.

App Server remains experimental. AppImage uses X11/XWayland and depends on compatible
host graphics libraries. Mobile background push and desktop auto-update are not
implemented. The relay transport and credentials are unchanged.

## Verify before installing

The release inventory, signatures, checksums and provenance must pass before the
pipeline publishes this prerelease. Follow the [release runbook](../release-runbook.md)
to verify downloads. Signed checksums do not replace Windows publisher trust.
