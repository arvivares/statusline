# Statusline 0.1.30 Beta

Companion opens directly from the menu-bar icon on macOS 27 again, discovers
more Claude Code installations automatically and makes service selection clearer.
Installers are built from the signed `v0.1.30` tag after release validation.

## What's improved

- **macOS 27 menu-bar clicks:** left click opens or closes Companion, right
  click keeps the context menu, and clicking outside still hides the window.
  This uses a narrowly scoped backport of the official tray-icon fix, with
  recorded provenance and integrity tests. Windows/Linux tray code is unchanged.
- **Automatic Claude Code discovery:** detect more native, npm, Homebrew,
  WinGet, Scoop and version-manager installations across macOS, Windows and
  Linux, including common locations missing from GUI applications' PATH.
  Discovery inspects local file metadata only; it does not run found launchers.
- **Explicit Claude activation:** a detected Claude Code installation offers
  **Enable quota** with the configuration-change disclosure beside the action.
  Nothing is enabled automatically. Activation preserves the existing status
  line, and pending, error and retry states stay in sync with Settings.
- **Consistent identities:** OpenAI · Codex, Google · Antigravity and
  Anthropic · Claude-Code. Other limits uses tool names and a visible chevron
  to indicate that each row is a button. Existing keyboard interaction remains.
- English, Spanish and English-fallback behavior are preserved. Codex's
  automatic quota selection from 0.1.29, account settings, pairing, encryption
  and updater contracts remain unchanged. No re-pairing is required.

## Distribution

Includes Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG and
Android `0.1.30 (26)` APK/AAB files. Android includes the corrected Google /
Antigravity identity; its sync, QR and widget behavior is unchanged. Install
the APK directly; the AAB is for Google Play, not direct installation.

iOS source includes the matching identity change, but this release **does not
build or upload iOS**. Its recorded version remains `1.1.1 (10)`; a separate
build and store submission are required to deliver the new labels on iPhone.
No Google Play/App Store submission, website or relay deployment is performed.

## Known beta limitations

- Frontend tests and isolated browser QA cover activation consent, no automatic
  settings changes, error/retry states, keyboard navigation and EN/ES/fallback.
  Rust tests cover bounded cross-platform discovery without executing launchers
  or changing account settings. Native CI checks all three desktop platforms.
- An isolated native probe passed on macOS 27.0: real OS mouse events exercised
  left-click toggle, right-click menu, menu replacement and outside-click hide.
  This is not an installed-package upgrade test. macOS 26 interaction, final
  installer upgrades and real Windows/Linux Claude sessions remain device QA.
- Claude quotas still require the user's explicit status-line bridge activation
  and a Claude Code session response. Installing Claude desktop alone does not
  provide a quota source; discovery is not a live account-quota request.
- The new Android label has automated validation; no new physical Android
  device test or iOS build is claimed for this GitHub release.
- Windows EXE/MSI remain **unsigned previews without Authenticode**, marked
  `.unsigned`. SmartScreen or organizational policy may warn or block them.
  Do not disable security protections.
- Linux package signatures, macOS Developer ID signing/notarization, Android
  signing and final-payload updater signatures remain mandatory. Mobile
  background/widget refresh scheduling remains controlled by the OS.
