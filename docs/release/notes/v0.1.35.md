# Statusline 0.1.35 Beta

Dependency maintenance for the cross-platform Companion and release tooling.
Existing accounts, discovered services, encrypted synchronization, pairing and
notification preferences are preserved.

## What's changed

- Align native Tauri and its JavaScript API/CLI on **2.12.1**, with native and
  JavaScript dialog **2.8.1**. Release preflight still rejects version drift.
- Replace the temporary macOS 27 tray backport with official **tray-icon
  0.25.1**, which includes the same upstream click-forwarding correction.
  Left-click toggling, right-click menus and outside-click hiding are preserved.
- Upgrade **minisign-verify to 0.3.0** in production and its lightweight test
  harness. The embedded updater public key and signing format are unchanged;
  the previous published updater signature was verified during dependency review.
- Update Tauri build tooling, Vite, Vitest, relay TypeScript types and reviewed
  Gradle CI actions. No new telemetry, quota source or collection is introduced.
- Retain **Android 6/API 23** and WorkManager **2.11.2**. The proposed 2.12.0
  update was not merged because it requires Android 7/API 24.

## Distribution

Includes Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG,
Android **0.1.35 (32)** APK/AAB and final-payload Companion updater signatures.
GitHub publication is configured as **Latest**, while product maturity remains beta.
Platform labels do not rename assets or alter updater URLs.

Windows installers remain **unsigned previews without Authenticode**.
SmartScreen or organizational policy may warn or block them; do not disable
security protections. Linux signatures, macOS Developer ID signing/notarization,
Android signing and updater signature gates remain mandatory.

iOS stays recorded at **1.1.3 (12)**. This release does not upload to App Store
Connect or Play Console, deploy the relay, migrate D1 or replace live pairings.

## Validation

- Dependency PR CI passed native checks and the production-module runtime tests
  on macOS, Windows and Linux before the maintenance changes were merged.
- On macOS **27.0 (26A428)**, the isolated native tray probe passed OS-generated
  left-click open/close, right-click menu/action replacement and outside-click
  hiding. It did not load agents, credentials, relay or actual Companion settings.
- Dependency review passed 314 desktop tests, release preflight, production
  frontend build, localization, formatting, docs and locked native tests.
- The release pipeline must pass its own preflight, native builds, installer
  smoke tests, signatures and complete inventory/provenance checks before
  automatic publication; preparing these notes does not claim that publication.

## Known beta limitations

- Installed-package upgrades, physical Windows/Linux desktop interactions,
  macOS 26 and native file-picker QA are distinct from compilation and fixture tests.
- Strict Clippy reports existing warnings in unchanged application/test code;
  this maintenance release does not claim a clean `-D warnings` run.
- Existing provider availability, five-minute collection cadence and best-effort
  push delivery limits still apply. No new push delivery behavior is introduced.
- Windows is not Authenticode-signed; Linux DEB/RPM updates use package managers.

## Verify before installing

Follow the [release verification guide](../release-runbook.md#independent-verification)
to verify checksums, Linux signatures and build provenance. Never share pairing
links, credentials or unreviewed diagnostic logs.
