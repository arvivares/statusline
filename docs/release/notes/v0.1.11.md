# Statusline 0.1.11 Beta

This beta standardizes English and Spanish across Statusline Companion, Android and
native widgets while preserving the Data Plane design. Apple source changes are also
included in the repository; the iPhone update will be distributed separately.

## What's new

- The primary system language selects Spanish or English. All other languages fall back
  to English, even when Spanish is a secondary system language.
- A shared catalog normalizes 403 messages across screens, QR pairing, accessibility,
  usage errors and desktop tray menus.
- Dates and relative times follow the selected UI language instead of being fixed to
  Spanish. Stored quota data, private pairing links and the relay protocol are unchanged.
- Compact translated widget labels preserve the Data Plane layout. Android widgets
  refresh their text when the system language changes, including Android 6 compatibility.
- Automated checks reject missing translations, outdated generated resources and new
  untranslated UI literals.

## Downloads and updates

- Linux x64: DEB, RPM and AppImage, each with a detached OpenPGP signature.
- macOS Apple Silicon and Intel: universal DMG and PKG, signed and notarized by Apple.
- Android: signed APK for direct installation and AAB for Google Play (`versionCode 7`).

Install the update from the same distribution channel as your existing installation.
The direct APK and Google Play use different signing keys; switching between them
requires uninstalling the existing app and pairing again. Generating this AAB does not
submit it to Google Play automatically.

The iPhone localization update is not included in these downloads and has not been
submitted to TestFlight/App Store by this pipeline. The separately recorded iOS store
version remains `1.0 (2)`.

## Verify before installing

The release includes `RELEASE-MANIFEST.json`, `SHA256SUMS.txt`, its detached signature and
the Linux verification key. Publication requires complete inventory, package-signature,
macOS notarization, checksum and GitHub build-provenance checks. See the
[release runbook](../release-runbook.md) for verification commands.

## Known beta limitations

- Windows is not included in this prerelease. Installers remain deferred until SignPath
  Foundation signing is configured.
- Mobile synchronization is foreground or user initiated; APNs/FCM notifications are
  not implemented. Automatic desktop updates are not enabled.
- The hosted relay uses Cloudflare Workers and D1; the self-hosted Linux adapter is
  planned but is not included in this release.
- Operating-system dialogs and external websites may use their own language settings.
- Codex App Server is experimental and may require future compatibility updates.
