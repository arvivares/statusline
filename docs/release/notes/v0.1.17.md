# Statusline 0.1.17 Beta

Statusline Companion can now check GitHub Releases for a newer version and offer
to download and install it. Your quota view, Codex session and encrypted pairing
are unchanged.

## What's new

- Automatic version checks run natively after startup and every six hours while
  the companion is running. You can turn them off or check manually in Updates.
- A compact Data Plane notice appears when the companion has focus. Hidden
  windows do not interrupt your work; the notice waits until you reopen them.
  Choose **Later** to dismiss that version or **Download & install** to proceed.
- Downloads show progress and must pass the updater's cryptographic signature
  verification before installation. Errors do not silently launch an installer.
- macOS uses the signed/notarized universal application; Windows preserves MSI
  or NSIS installation type; Linux AppImage replaces the existing AppImage.
  DEB/RPM and unknown installation types link to the official release downloads
  for installation through the package manager instead of requesting root access.
- The updater and its errors follow the existing English/Spanish system-language
  policy. Unknown languages fall back to English.
- Integrate Dependabot PR #20: Vitest 5.0.0, a development-only test dependency.

## First installation and downloads

**Install 0.1.17 manually once.** Earlier versions have no updater and cannot
discover this feature. Automatic checks in 0.1.17 will offer future eligible
releases, not reinstall the current version. Downloading and installing always
requires your confirmation and may restart the companion or invoke OS permissions.

- macOS Apple Silicon and Intel: universal DMG and PKG, signed and notarized.
- Windows x64: **unsigned preview** NSIS `.unsigned.exe` and `.unsigned.msi`.
  Updater signatures are separate from Authenticode: SmartScreen or organization
  policy can still warn or block installation. Never disable security protections.
- Linux x64: DEB, RPM and AppImage, with detached OpenPGP signatures.
- Android: signed APK and AAB, `0.1.17` (`versionCode 13`). Update through the same
  channel you used to install; Google Play submission remains a separate action.

iOS remains `1.0.1 (6)` for its separate TestFlight validation. GitHub Actions does
not build/upload iOS or change App Review. This release does not claim new store
approval or completed physical-device updater validation.

## Known beta limitations

GitHub connectivity and API limits can delay version checks. No Codex credentials,
quota snapshots or pairing secrets are included in update requests. GitHub receives
normal request metadata; see the [privacy policy](../../../PRIVACY.md).

Only a running companion can check for updates. Sleep delays checks. Packaged
AppImages must be launched normally, not from an extracted diagnostic AppDir.
The existing X11/XWayland rendering requirements remain unchanged.

Before broad rollout, validate a real **0.1.17 → later version** upgrade on macOS,
Windows MSI, Windows NSIS and Linux AppImage, including restart and pairing
preservation. Tests and signing checks are not a substitute for this device QA.
See [companion updates](../../architecture/companion-updates.md).

## Verify before installing

The pipeline publishes only after all required installers, updater signatures,
checksums and provenance pass validation. Preparing these notes is not proof that
the release pipeline has completed.
