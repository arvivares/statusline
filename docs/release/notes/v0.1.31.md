# Statusline 0.1.31 Beta

Companion now discovers Claude Code and activates its documented status-line
bridge automatically when the Claude Code CLI is installed.

## What's improved

- **Automatic Claude Code activation:** the Companion connects the detected CLI
  without requiring a separate button press. Claude Desktop-only installations
  remain informational because the desktop app does not expose the status-line
  quota payload.
- **Safe configuration handling:** existing Claude settings are preserved,
  compatible custom status lines are chained and restored on disconnect, and
  unknown or malformed status-line values are left untouched.
- **Privacy boundary:** Companion reads only the documented `rate_limits` data
  delivered by Claude Code. Credentials, conversations, transcripts and prompts
  are never queried or persisted.
- **Existing mobile and relay contracts remain unchanged.** Claude is visible
  only in the Companion until its mobile adapter is released.

## Distribution

Includes Windows EXE/MSI, Linux AppImage/DEB/RPM, universal macOS DMG/PKG and
Android `0.1.31 (27)` APK/AAB files. Windows installers remain unsigned previews
without Authenticode; SmartScreen or organizational policy may warn or block
them. The iOS build remains on its separately managed App Store release track.

## Validation

- Rust Claude module tests: 23 passed.
- Rust formatting and repository diff checks passed.
- No relay schema or mobile pairing changes are included.

## Known beta limitations

- Claude Code must run at least one session response before a quota sample is
  available. Claude Desktop alone does not expose the required status-line
  payload.
- Windows EXE/MSI remain **unsigned previews without Authenticode**. SmartScreen
  or organizational policy may warn or block them; do not disable security
  protections.
- Linux package signatures, macOS Developer ID signing/notarization, Android
  signing and final-payload updater signatures remain required for distribution.
