# Statusline 0.1.27 Beta

Candidate: Claude Code live quota through the documented status-line bridge.
This release is built from the signed `v0.1.27` tag; preparing this file does
not publish installers.

## What's new

- Companion discovers Claude Code installations without executing them. The
  Claude service appears only when Claude Code is present or has reported a
  bridge sample; absent services stay hidden.
- Settings › Services adds an explicit **Connect Claude Code** action. It adds
  a `statusLine` command to Claude Code's `settings.json`; Claude Code provides
  the documented five-hour and weekly rate-limit windows to the local bridge.
- The bridge keeps only quota percentages, reset times and sample timestamps.
  Session, transcript, workspace, prompt, cost and credential data are not
  stored or sent by Statusline. An existing command status line is chained and
  restored when disconnected.
- Claude's ready reading is added to the additive desktop services inventory
  without changing Codex relay credentials, existing pairings or the legacy
  Codex projection. Mobile Claude UI remains a later sprint; current mobile
  clients ignore the unknown provider entry.
- The normal GitHub release remains Latest, with platform labels for Windows,
  Linux, macOS and Android. The Android AAB is a Google Play artifact and is
  not directly installable.

## Known beta limitations

- Claude Code reports quota after a session response and only for accounts that
  expose plan windows. API-key and cloud-provider sessions may report no plan
  quota. Windows and Linux real-session validation remains pending; this
  candidate is intended for physical macOS validation first.
- Windows installers remain **unsigned previews without Authenticode**. Their
  filenames contain `.unsigned`; SmartScreen or organizational policies may
  warn or block installation. Do not disable security protections.
- Linux signatures, macOS Developer ID/notarization and Android release
  signing remain required before publication. Google Play submission is a
  separate step, and iOS remains a separate App Store delivery.
